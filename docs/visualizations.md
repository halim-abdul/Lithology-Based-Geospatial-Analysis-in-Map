# Visualization guide

The project uses several complementary views rather than relying on a single map.

- **Lithology map:** spatial distribution of rock categories.
- **Fault-type map:** geographic distribution of kinematic classes.
- **Lithology counts:** reveals severe class imbalance before interpretation.
- **Fault-type counts:** compares normal, inverted, dextral, sinistral, extension, and pressure observations.
- **Lithology × fault heatmap:** within-lithology composition rather than raw counts.
- **Strike rose diagram:** axial orientation summary for structural planes.
- **Dip distributions:** compares inclination by lithology.
- **Sampling-density map:** distinguishes where measurements are concentrated from where a geological feature is necessarily more abundant.

All plots are generated from source data by scripts in `scripts/`.
